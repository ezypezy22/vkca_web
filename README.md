# About VK Contest Analyzer

**VK Contest Analyzer** is a real-time competitive intelligence tool for N1MM+ contest logging. It reads your live `.s3db` log during a contest and tells you exactly where to focus to maximise your score — QSOs, multipliers, band efficiency, propagation, and session/block countdowns.

Built and maintained by **VK2YI**.

## Current version

`26.7.23`

Versions follow a `YY.M.patch` scheme:

- `YY` — two-digit year of release
- `M` — month of release (no leading zero)
- `patch` — incrementing patch number for that month, reset to `1` at the start of each new month's releases

Example: `26.7.1` = the 1st release in July 2026.

## Features

- 📊 Overview — live contest summary
- 📡 DX Cluster — spot feed integration
- 🎯 Missing Mults — multipliers not yet worked
- 📋 Worked — full worked-station log
- ⚡ Rate Analysis — QSO rate tracking
- 📡 Band Breakdown — per-band performance
- ⚠️ Dupe Checker — duplicate QSO detection
- 🌐 Propagation — band-opening intelligence
- 🛠 Debug Mults — multiplier troubleshooting
- ⏪ Score Replay — replay contest progress
- 😴 Fatigue — operator fatigue tracking
- 📈 Year on Year — historical comparison
- 🏁 Pace Tracker — pace against goals/history

& Many more features.... 

Available as a native desktop app and a web/HUD mode (`web/`) for browser- or pop-out-window-based dashboards.
